这是什么
----------------------------------------------------------------
米家自动化极客版自动登录助手：一次登录小米账号，之后自动获取并填入
6 位登录码，断连自动补码。非抓包，桌面版不需要安装浏览器扩展。

小提示：在浏览器设置里找到「使这些站点保持活动状态」（内存节省模式白名单），
把米家极客版网页地址加进去，可明显减少页面闲置后自动断联的频率。


第一次运行可能遇到的提示
----------------------------------------------------------------
【Windows】
1. SmartScreen 蓝底提示「Windows 已保护你的电脑」：
   本工具为个人开源免费项目，未购买商业代码签名证书。
   可核对 GitHub Release 页面的 SHA256SUMS.txt 校验值，确认无误后
   点「更多信息」→「仍要运行」。
2. 若提示缺少 VCRUNTIME140.dll / MSVCP140.dll：
   安装微软官方「Visual C++ Redistributable (x64)」运行库即可。

【macOS】
1. 若提示「已损坏，无法打开」或「无法验证开发者」（因未购买 Apple 公证）：
   将 EzMiGeek.app 拖入「应用程序」后，在终端执行一次：
     xattr -cr /Applications/EzMiGeek.app
2. 在 macOS 15 及以上系统首次扫描局域网中枢时，系统会弹窗询问「本地网络」
   访问权限，请选择「允许」。


关于你的账号与隐私
----------------------------------------------------------------
· 登录凭据只保存在你本机：
    Windows：使用系统 DPAPI 加密，绑定当前电脑与当前用户；
    macOS  ：存入系统登录钥匙串（Keychain），磁盘只保留指针文件。
  换电脑或重装系统后需重新登录一次。
· 日常运行期间所有网络请求仅发往小米官方接口与本机局域网中枢，不经过任何
  第三方服务器，不采集、不上传用户数据。
· 只有当你主动在托盘右键点击「检查更新」时，程序才会请求一次 GitHub
  Releases API 对比最新版本号。
· 本机日志（agent.log）不会记录 6 位登录码明文、Cookie 或 Token 值。


面板与设置说明
----------------------------------------------------------------
设置卡共 5 行（拨动开关立刻生效并落盘）：
  1. 当前登录码       ：展示最新 6 位码；点击整行复制，点击左侧 ↻ 图标立即取新码
  2. 登录成功后收进托盘：自动填码成功后自动把面板隐藏到系统托盘/菜单栏
  3. 双击托盘图标打开网页：开=双击托盘直接开极客版，关=双击仅唤出主面板
  4. 开机自动启动      ：Windows 写当前用户注册表；macOS 写 LaunchAgents plist
  5. 重新登录小米账号   ：登录态过期或切换账号时重新登录

配置文件位置：
  Windows：%LOCALAPPDATA%\EzMiGeek\settings.json
  macOS  ：~/Library/Application Support/EzMiGeek/settings.json

纯文本 JSON，可用文本编辑器修改；删掉该文件可恢复全部出厂默认设置（不影响
登录凭据和登录统计）：
  · WaitMin (1~60)    ：单次取码最长重试分钟数（每轮开跑热重载，无需重启）
  · RetrySec (1~60)   ：取码失败重试间隔秒数（每轮开跑热重载）
  · FailMax (1~9)     ：连续填码失败转人工次数（每轮开跑热重载）
  · HubIp             ：手动指定中枢 IP（如 "192.168.5.3" 或 "192.168.5.3:80"，
                        省略端口先试 8086 再试 80；留空 = 自动发现；热重载）
  · AutoFullscreen    ：打开极客版网页时是否全屏（true=全屏，false=最大化；热重载）
  · LocalCodeService  ：是否启用本机 127.0.0.1 取码 IPC 服务（默认 true，
                        供本机其他工具复用已登录态；设为 false 后重启即可关闭）


界面语言（右下角「中 / EN」）
----------------------------------------------------------------
点击右下角胶囊可即时在中英文间切换，面板与托盘右键菜单同步刷新并自动保存。
运行日志统一保持中文，方便排障检索。


程序使用哪个浏览器
----------------------------------------------------------------
优先使用系统默认浏览器：
  · Chrome / Edge / Brave / Vivaldi / Arc / Opera 等 Chromium 系浏览器：
    使用独立专用配置目录启动（不污染你日常浏览器的账号与历史），支持全自动填码。
  · Safari / Firefox 等非 Chromium 浏览器：
    自动走降级模式——打开极客版网页，同时自动取码并复制到剪贴板，粘贴即可登录。


遇到问题与日志反馈
----------------------------------------------------------------
点击面板「查看日志」或托盘右键「打开日志文件夹」，可查看以下日志：
  · agent.log（运行日志，超过 2 MB 自动滚动归档为 agent.log.1）
  · crash.log（仅在发生未捕获异常崩溃时生成）

欢迎到 GitHub Issues 提交问题并附上日志片段：
  https://github.com/Ezer521/EzMiGeek/issues


卸载与清理本机数据
----------------------------------------------------------------
本程序为绿色版：
  1. 若开启过「开机自动启动」，请先在面板上关闭该开关（即时清理启动项）。
  2. 退出托盘程序后直接删除程序文件夹或 EzMiGeek.app。
  3. 如需一并清除本机凭据、浏览器独立配置、设置与日志，退出后删除数据目录：
       Windows：%LOCALAPPDATA%\EzMiGeek
       macOS  ：~/Library/Application Support/EzMiGeek（并可在钥匙串访问中删除
                EzMiGeek.credentials 与 EzMiGeek.token-cache 条目）
